# XML Student Management System 🎓

A Student Management System built using **XML, XSD, XSLT, XPath, HTML, CSS, and JavaScript**.

The project stores student information in XML and transforms it into a user-friendly HTML student report using XSLT.

---

## 🛠️ Technologies Used

- XML
- XSD
- XSLT
- XPath
- HTML
- CSS
- JavaScript

---

## ✨ Features

- Student information management
- Multiple student records
- Student ID and status
- Gender and date of birth
- Course and department information
- Email and phone details
- Complete address information
- Subjects and marks
- Total marks calculation
- Average marks calculation
- Grade calculation
- Pass/Fail result
- Student ranking
- Sort students by average marks
- Total student count
- Course-wise student count
- Search student by name
- Filter students by course
- Filter students by gender
- XSD validation
- XSLT transformation
- Responsive HTML table
