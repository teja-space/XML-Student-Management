# XML Student Management System

A Student Management System created using XML, XSD and XSLT.

## Technologies

- XML
- XSD
- XSLT
- XPath
- HTML
- CSS

## Features

- Student information management
- Multiple student records
- Subject and marks information
- Total marks calculation
- Average marks calculation
- Grade calculation
- Pass/Fail result
- Student status
- Address information
- XSD validation
- XSLT transformation
- Sorted student records

## Project Files

### students.xml

Contains all student data.

### students.xsd

Defines the structure and validation rules for the XML data.

### students.xsl

Transforms the XML data into an HTML table.

## How to Run

1. Open the project in VS Code.
2. Install Live Server.
3. Open `students.xml`.
4. Right-click and select **Open with Live Server**.
5. The Student Management System will open in the browser.
